This website is written in Markdown in neovim and built into plain HTML by swag, a small static site generator I wrote in Go. Pandoc renders the Markdown and highlights the code. A small CSS file handles the presentation, and the pages use system fonts. There is no client-side JavaScript.

Posts and pages live in content/, the page templates in layouts/, and static assets in static/. swag writes the finished site to docs/, which GitHub Pages serves. I describe the setup in Adding swag to my zero-dependency static website generator. The Emacs and Org setup it replaced is in A zero-dependency static website generator.

The site intentionally has no analytics, tracking, comments, or cookie banner. You can follow new posts through RSS or reach me at nate@vetr0s.dev.
