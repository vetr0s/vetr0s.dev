# vetr0s.dev

## Commands
- build: `swag build`
- watch: `swag serve`

## Key directories
- `content/`: Markdown source for the home page and posts.
- `layouts/`: HTML templates and partials.
- `static/`: Files copied as is into the site, including `style.css`.
- `docs/`: Generated site served by GitHub Pages. Never edit by hand.

## Conventions
- Commit the rebuilt `docs/` with every source change.
- Keep this file up to date. When you learn a practice or standard for this project, add it here.
